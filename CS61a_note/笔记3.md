# 数据抽象
- 是将复合数据值的行为方式和实现细节区分开来的一种思维方式
## 步骤
- 一厢情愿：假设已经实现了数据的情况下去思考该如何去操作数据
- 实现数据
## 一般标准：抽象屏障
一般将数据分为三层
- 高层使用数据
- 中层表示数据，细分为构造器和选择器
- 底层实现数据
由此可见：数据是任何满足特定的行为的客体

# 序列
## 序列属性
- 长度
- 元素选择
- 成员资格
- 切片：返回一个新序列，内容是原序列的一段连续范围
# 类型
len（）返回长度
- 列表
- 范围
- 元组：不可变
## 序列操作
### 遍历
- 遍历常用for循环
```python
for <name> in <expression>: 
	<suite>
```
序列解包：将多个名称绑定到固定长度序列中的多个值的模式称为序列解包
范围（range）：返回一段连续序列，不包括终点值，第三个参数为步长
### 处理
#### 内容
- 映射
- 选择
- 聚合
#### 方式
- 列表推导式
- 高阶函数

## 字符串
 - 成员资格
 - 多行字面量
 - 字符串强制转换（str()）
## 树
- 列表具有闭包性，便于构建层级结构
- 树由标签和一系列分支构成，每个分支也都是树，因此需要两个选择器和一个构造器
## 链表
- 链表是由首元素和尾元素组成的嵌套对
- 可递归构造也可迭代构造
# 可变数据
- 模块化是将项目分成好几个独立且相互联系部分，一种很好的实践是引入随时间而发生变化的数据，因而就有了面向对象编程，其核心是向数据添加状态
## 对象隐喻
- 对象是值和行为的结合，可以直接表达某些信息，也可以用行为表达一些东西
## 序列对象
- 列表具有局部状态，是可变的
	- 元组是不可变的
- 多个名称可以绑定同一个对象，用is 或 is not 判断是否是同意对象，统称数据共享与识别
