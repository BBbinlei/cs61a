# 高阶函数
- 通用方法的抽象
### 特点
- 将函数作为参数，运用到函数体操作中
```python
>>> def improve(update, close, guess=1):
        while not close(guess):
            guess = update(guess)
        return guess
```
- 将函数作为返回值，返回值为***嵌套定义***的
#### 嵌套定义
- 可在函数体内部嵌套定义函数,（**基于词法作用域的拓展**）
```python
>>> def compose1(f, g):
        def h(x):
            return f(g(x))
        return h
```
### 环境
#### 词法作用域
- 局部定义的函数也可以访问整个定义作用域内的名称绑定
##### 实现所需特点
- 每个局部帧都有其父环境
- 每个局部帧都能够继承父环境中的名称绑定
##### 结果
- 局部定义的函数仍能够访问关联环境中的名称绑定

## 柯里化
- 使用高阶函数，将多参数函数转化成单参数函数链
```python
>>> def curry2(f):
        """返回给定的双参数函数的柯里化版本"""
        def g(x):
            def h(y):
                return f(x, y)
            return h
        return g
>>> def uncurry2(g):
        """返回给定的柯里化函数的双参数版本"""
        def f(x, y):
            return g(x)(y)
        return f
>>> pow_curried = curry2(pow)
>>> pow_curried(2)(5)
32
>>> map_to_range(0, 10, pow_curried(2))

2

32
64
128
256
512
```
## lambda 表达式
- 用lambda表达式可以创建临时函数，不需要其与名称绑定，就能计算未命名函数
```python
lambda              x         :              f(g(x))
"A function that    takes x   and returns    f(g(x))"
```
```python
>>> def compose1(f, g):
        return lambda x: f(g(x))
```
```python
>>> compose1 = lambda f,g: lambda x: f(g(x))
```
## 抽象和一等函数
- 抽象思考：不断觉察程序中的基本抽象，然后对其进行拓展
- 一般而言，编程语言会对计算元素的操作方式施加限制。拥有最少限制的元素可以获得一等地位（first-class status）。这些一等元素的“权利和特权”包括：

1. 可以与名称绑定
2. 可以作为参数传递给函数
3. 可以作为函数的结果返回
4. 可以包含在数据结构中

Python 授予函数完全的一等地位，由此带来的表达能力的提升是巨大的。
## 函数装饰器
- 函数装饰器是一种允许你在不修改原函数代码的情况下，为该函数添加新功能的特殊函数。
```python
>>> def trace(fn):
        def wrapped(x):
            print('-> ', fn, '(', x, ')')
            return fn(x)
        return wrapped

>>> @trace
    def triple(x):
        return 3 * x

>>> triple(12)
->  <function triple at 0x102a39848> ( 12 )
36
```

```python
>>> def triple(x):
        return 3 * x
>>> triple = trace(triple)
```

## 递归的变体
### 互递归
- 两个函数间反复相互调用
```python
>>> def is_even(n):
        if n == 0:
            return True
        else:
            if (n-1) == 0:
                return False
            else:
                return is_even((n-1)-1)
>>> def play_alice(n):
        if n == 0:
            print("Bob wins!")
        else:
            play_bob(n-1)

>>> def play_bob(n):
        if n == 0:
            print("Alice wins!")
        elif is_even(n):
            play_alice(n-2)
        else:
            play_alice(n-1)

>>> play_alice(20)
Bob wins!   
```

## 应用
### 递归打印
- print在递归的前后影响整体打印的顺序
```python
>>> def cascade(n):
        """打印数字 n 的前缀的级联"""
        if n < 10:
            print(n)
        else:
            print(n)
            cascade(n//10)
            print(n)

>>> cascade(2013)
2013
201
20
2
20
201
2013
```
### 分割数
- 思路：递归将问题不断变小，意料之外的部分直接不计数
```python
>>> def count_partitions(n, m):
        """计算使用最大数 m 的整数分割 n 的方式的数量"""
        if n == 0:
            return 1
        elif n < 0:
            return 0
        elif m == 0:
            return 0
        else:
            return count_partitions(n-m, m) + count_partitions(n, m-1)

>>> count_partitions(6, 4)
9
>>> count_partitions(5, 5)
7
>>> count_partitions(10, 10)
42
>>> count_partitions(15, 15)
176
>>> count_partitions(20, 20)
627
```
